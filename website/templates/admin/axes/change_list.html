{% extends "admin/change_list.html" %} {% comment %} Changelist for django-axes' three login-record models (#1460). Axes ships no admin templates, and the admin looks for admin//change_list.html before its default, so this one template covers all three pages without re-registering axes' ModelAdmins. It only adds a short explanation under the page title, because names like "Access attempts" don't say what is in them, and these pages get read during a lockout. The numbers (10 wrong passwords, 30 minutes, 1,000 rows) mirror AXES_* in settings.py and axes' own failure-log cap; test_login_throttle.py fails if they drift. All three pages are superuser-only (axes' permissions). {% endcomment %} {% block content_title %} {{ block.super }}
{% if opts.model_name == "accessattempt" %}

Usernames that are currently building up wrong passwords. Ten in a row locks that username out of /admin for 30 minutes, and a correct password clears its count, so this page is usually empty.

To unlock someone now, tick their row, choose “Delete selected access attempts” and click Go.

{% elif opts.model_name == "accesslog" %}

Every successful sign-in to /admin, with the time the person signed out. A blank logout time means they are still signed in, or their session expired without signing out.

The IP address is the CSE web proxy's, not the person's own, which is why the throttle counts by username rather than address.

{% elif opts.model_name == "accessfailurelog" %}

Every wrong password, kept after the count on Access attempts resets (up to 1,000 per username). A burst of failures for one username means someone is guessing its password.

A username that matches no account is stored as a hash, so a password typed into the username box by mistake is never saved.
